# 江西智慧教育平台学习园地资源批量下载工具

## 简介

本工具用于批量下载江西智慧教育平台（https://xxyd.jxeduyun.cn）学习园地中的教育资源。支持按学段、年级、学科、版本、册别等条件筛选和下载资源。

## 功能特点

- **多条件筛选**：支持按学段、年级、学科、版本、册别、年份等条件筛选资源
- **完整分页**：突破API限制，自动分页获取所有资源
- **批量下载**：支持批量下载学生书、教师书、音频、视频等资源
- **单元分组**：自动识别并按单元分组显示资源
- **断点续传**：已下载的文件不会重复下载
- **重试机制**：下载失败自动重试3次

## 使用方法

### 1. 交互式版本（推荐）

```bash
python jx_downloader.py
```

运行后会显示菜单，按提示选择操作：

```
============================================================
  江西智慧教育平台 - 学习园地资源下载工具
============================================================

请选择:
  1. 按条件搜索并下载资源
  2. 按版本和册别浏览下载
  3. 设置下载目录
  4. 退出程序
```

### 2. 命令行版本

```bash
# 列出所有可用的年级和学科
python downloader.py --list

# 下载所有资源
python downloader.py --all

# 下载七年级语文资源
python downloader.py --grade 七年级 --subject 语文

# 下载小学阶段所有资源
python downloader.py --stage 小学

# 下载指定年份的资源
python downloader.py --year 2026 --limit 100

# 下载资源到指定目录
python downloader.py --grade 三年级 --output ./downloads
```

## API分页说明

本工具使用 `page` 参数（不带Num）进行分页，可正常获取所有资源：

```python
# 正确的分页参数
params = {"page": 1, "pageSize": 10}  # ✅ 正常分页

# 错误的分页参数
params = {"pageNum": 1, "pageSize": 10}  # ❌ 始终返回10条
```

## 常见问题

### Q: 为什么下载的文件是空的？

A: 检查网络连接，或尝试增加重试次数。

### Q: 如何下载指定单元的资源？

A: 使用交互式版本，选择"按单元下载"功能。

### Q: 支持下载视频吗？

A: 支持，但需要在下载选项中选择"全部下载"。

### Q: 下载速度慢怎么办？

A: 可以适当增加 `time.sleep()` 的时间间隔，避免请求过快被限制。
